# 🎯 Features Guide - How to Use

## 🔍 Product Filtering & Sorting

### Search Products
1. Navigate to the **Products** page
2. Use the search bar at the top to search by product name or description
3. Click "Clear" button to reset search

### Filter by Price
1. Find the "Price Range" section in the filter panel
2. Enter minimum price in the first input
3. Enter maximum price in the second input
4. Click "Reset" to restore full price range

### Sort Products
Choose from 5 sorting options:
- **Latest First** - Newest products appear first
- **Price: Low to High** - Cheapest products first
- **Price: High to Low** - Most expensive products first
- **Name: A to Z** - Alphabetical order
- **Name: Z to A** - Reverse alphabetical order

### Filter by Category
- Click any category button to filter products
- Click "All" to show all products
- Active category is highlighted with gradient background

### Combine Filters
All filters work together! You can:
- Search + Filter by category + Sort by price
- Set price range + Filter by category + Sort alphabetically
- Any combination you need!

## 🛍️ Shopping Features

### Browsing Products
1. Go to **Products** page
2. Browse through the grid of products
3. Hover over cards to see animations
4. Each card shows:
   - Product image
   - Category badge
   - Product name
   - Description preview
   - Price in USD and ETH
   - Stock status
   - Action buttons

### Viewing Product Details
- Click "View Details" button on any product card
- See full product information

### Adding to Cart
1. **Sign in first** (required to add items)
2. Click "🛒 Add" button on product card
3. Item is added to your cart

### Without Sign In
- You can browse all products
- You can use all filters and search
- You can view product details
- You must sign in to add items to cart
